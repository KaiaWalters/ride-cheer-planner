# Trip Tracker Pro

id like you to help me build an application using vue, typescript, nuxt, and node. The application will be used to help someone track. a long distanc e biking trip and trackin g their energy level at different points of the tirp. The trip plan can be shared and organized with other contributors who subscriebe to the same plan and can add details alongside the trip creator. 

Users should be able to create an account, create trips, add supplies to the trip, add destinations to the trip, and should be able to add pricing for supplies and lodging to the trip. 


Users should be able to add "cheerleaders" to a trip which mean subscribing friends and family to receive notifications from the app with updatses on the team's location. 


The code you write needs to be simple and follow solid principles.
